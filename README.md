# IPFS Kubo Railway Template

This example deploys a server of [Kubo](https://github.com/ipfs/kubo).

[![Deploy on Railway](https://railway.com/button.svg)](https://railway.com/deploy/job-ops?referralCode=C3Uv6n&utm_medium=integration&utm_source=template&utm_campaign=generic)

## ✨ Features

- Job Ops
- Reactive Resume
  - Browserless
  - Postgres
  - KeyDB
  - Bucket

## 💁‍♀️ How to use

- Click the Railway button 👆
- Fill in the variables
- Deploy! 🚄
